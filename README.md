Starlight Courier is a gravity-slingshot delivery game: drag to aim, launch past planets, ride their gravity, and land gently on the beacon planet to deliver parcels across eight star systems. Synthesized sound, no assets, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
